This entry writes a single Wi-Fi network name of at most 32 characters: the funniest name that hints at a whole story, as seen in a phone's network list. The joke lands first, the story follows — a dad who went out for milk and never came back, and the year is the punchline.

**He left for milk. That was 2019.**

## Run it

```sh
node main.ts
```

It writes the 32-character Wi-Fi name to `/output/entry.txt` with no trailing newline, then reads the file back and verifies it is byte-identical to the entry line.
